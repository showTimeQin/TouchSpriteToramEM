# TouchSpriteToramEM

《托兰异世录》（Toram Online）手游的**触动精灵（TouchSprite）自动挂机脚本 —— 噩梦脚本**，作者 Kami桑。自动打噩梦 BOSS，支持活动版本、材料处理与清包。

## 功能

- 自动打「噩梦」BOSS（日志含 `开始噩梦`、`交任务`）
- 游戏渠道：小游 / 4399
- 版本模式：正常版本 / 活动版本 / 交任务 / 测试回城 / 测试清包
- 材料处理方式：删除 / 分解
- 传送点位置可选（第一 / 第二 / 第三个）

## 环境

- 触动精灵（TouchSprite）安卓端
- 分辨率固定 **720 × 1280**（脚本内检测宽高，不符会提示不支持）
- 启动密码：`1024`（见 `main.lua`）

## 文件

| 文件 | 说明 |
| --- | --- |
| `main.lua` | 主脚本：UI 配置、密码校验、启动挂机协程 |
| `720p.lua` | 720p 下的坐标 / 操作封装（回城、找 NPC、清包等） |
| `Tools.lua` | 工具函数（点击等） |
| `TSLib.lua` | 触动精灵库文件（二进制） |
| `ToramEM.tsproj` | 触动精灵工程文件 |

## 使用

将整个目录导入触动精灵，加载 `ToramEM.tsproj`，在界面选择渠道、版本模式、材料处理方式与传送点，输入密码后启动。
